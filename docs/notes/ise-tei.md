# 実験ノート: 伊勢物語の TEI 化と地名アノテーション

## 2026-10-18 底本の選定

目的は DLM 東海道分間之図に伊勢物語の歌枕の層を重ねること。本文は TEI にして placeName を付ける。
条件は、著作権が切れていて、IIIF 画像が公開されていること。

候補（どれも PDM で、IIIF マニフェストが取れることを確かめた）:

- A. 嵯峨本（慶長13・1608）国文研 鉄心斎文庫 200024817。126 コマ。九段はコマ 17〜22
- B. 佐佐木信綱 校註『伊勢物語』東京堂 明25（1892）NDL 877528。63 コマ。九段はコマ 19〜21。
  佐佐木は 1963 年没。1968 年より前に亡くなっているので、没後 50 年で保護が切れている
- C. 明和9（1772）吉文字屋版 山口大 棲息堂文庫 国文研 100262486。111 コマ。九段はコマ 18〜21。
  くらべて読む古典籍（ab.ldas.jp の shohon）で伊勢の基準本になっていて、OCR の質がよい

A に決めた。決め手は、やたがらすナビが A の翻刻を全段公開していること。
翻刻は行どりとコマの区切り（「／s17l」）を保っており、「著作権が存在しません」と明記されている。
TEI の lb・pb と画像の対応がそのまま作れる。

却下した案:
- B は、本文と注が同じ面に入り混じる組み方。OCR から本文だけを抜く手間が大きい
- C は、翻刻を一から確かめ直すことになる
- 正宗敦夫『日本古典全集』（NDL 1194243）と博文館『日本文学全書』は、NDL でネット公開されていない
  （IIIF マニフェストが空で返る）

目的は地名を付けることなので、校訂は深くしない（本人の判断、2026-10-18）。
校訂本文（CC BY-SA 4.0）は使わず、翻刻だけを使う。こうすれば SA（同じ条件での公開）がかからない。

先行事例:
- 中川聡「嵯峨本『伊勢物語』」やたがらすナビ、Ver.1.0、2024。https://yatanavi.org/text/ise/
- 校異源氏物語テキストDB。https://kouigenjimonogatari.github.io/
- 山元啓史による伊勢物語の対訳ページ（本文は新編日本古典文学全集による）。
  https://cuckoo.js.ila.titech.ac.jp/~yamagen/ise/iseStat.php

## 2026-10-18 変換の試作

`scripts/yatanavi2tei.py` で、やたがらすナビの ise_1.0.zip を変換した。
zip の SHA-256 は 69548389c193a7363d9070de6a1dce0a86d76863aecc6b8fa16a4b3bac252776。

結果は 126 の div（125 段と奥書）、1,500 行、226 半丁。tei_all で検証が通った。
九段に placeName 19 か所（地名 11 件）を付けた。

自明でなかったこと:
- 「／sNNx」は「ここまでがコマ NN の x 側」という意味。段の終わりにも、コマの途中で印が付く。
  そのため次の段の頭は、同じ半丁の続きになる（印の並びが前に戻るように見えるが、誤りではない）
- 国書データベースのコマ番号は、マニフェストの canvas の順番と一致する（label が番号）
- 九段の「うつの山」と「しもつふさのくに」は、行をまたいでいる。
  そのため照合は行をつないだ文字列で行い、placeName の中に lb を入れた
- 九段の歌「するかなるうつの山辺の」の「するか」は、前後の文字で位置を絞って付けた

確かめた:
- 21 コマ目の画像を目で見て、右半分 9 行・左半分 7 行（歌の 2 行は字下げ）を確認した。TEI の行どりと一致する

確かめていないこと（限界）:
- 見開きの左右の境は、画像を縦に二等分した近似値。のどの位置は測っていない
  （21 コマでは、のどはほぼ中央にあった）
- 京・国名の座標は Wikidata の代表点で、粗い
- 八橋は Wikidata に項目が無い。座標は知立市八橋町の無量寿寺（Q11567552）で代用した
- 翻刻そのものを画像と一字ずつ突き合わせてはいない

地名の点は、kiko-tei の `tei2geojson.xsl` をそのまま使って GeoJSON にできた（11 点）。
